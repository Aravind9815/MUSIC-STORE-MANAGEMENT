# MUSIC-STORE-MANAGEMENT

This project analyzes **Music Store data using MySQL** to understand customer behavior, music genre preferences, and sales performance.
By writing advanced SQL queries, we identified top-spending customers, high-revenue cities and countries, popular genres and artists (especially Rock), and best-selling tracks.
The insights support data-driven decisions for promotions, customer segmentation, playlist strategies, and inventory optimization, making this project a strong demonstration of SQL and data analysis skills.
